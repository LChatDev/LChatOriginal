# LChatOriginal

Оригинальная версия LChat для контрибьютинга.

Исходники веб-версии LChat на PHP и JavaScript. Проект полностью разрабатывается с помощью ИИ; изменения требуют проверки перед эксплуатацией.

## Установка

1. PHP 8.2+ с pdo_mysql, mbstring, openssl, fileinfo и MySQL/MariaDB; Apache с mod_rewrite.
2. Скопируйте config.example.php в config.php, укажите свои параметры БД, случайный install_key и HTTPS-адрес сайта.
3. Разрешите PHP запись в data/ и files/. Откройте install.php и завершите установку.
4. Для звонков настройте собственный TURN в конфигурации. HTTPS обязателен для микрофона браузера, кроме localhost.

config.php исключён из Git. Не публикуйте рабочую БД, пароли, токены и пользовательские файлы.
Медиа-каталоги и внешние сервисы подарков/ИИ требуют отдельной настройки; они не включают пользовательские данные этого сайта.

## Вклад в проект

Создайте fork и ветку, внесите изменение и откройте pull request. Опишите проблему, решение и проверку на телефоне и ПК. Не меняйте конфигурацию рабочего сайта. Соблюдайте LICENSE и TELEGRAM_SOURCE.md; сторонние ресурсы имеют свои условия использования.

## Звонки

Можно войти с выключенным микрофоном. Экран показывает этапы входа и число подключённых участников. При блокировке воспроизведения доступна кнопка включения звука. После возвращения сети выполняется повторное соединение. Браузерные ограничения фоновой работы сохраняются.
